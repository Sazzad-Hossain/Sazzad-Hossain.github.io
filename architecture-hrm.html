BUSINESS LOGIC LAYER

LAYER 03

Services & Core Logic

Application Services

  • EmployeeService — Employee CRUD, code generation, reactivation
  • PayrollService — Salary processing, pay runs, payslip generation
  • LeaveService — Leave requests, balance tracking, workflow
  • AttendanceService — Clock-in/out, time tracking, reports
  • LoanService — Loan applications, approval/rejection, penalties
  • ReportService — 12+ report types, salary summaries, P&L
  • PFService — Provident fund contributions

Access Control & Middleware

  • Middleware: auth · verified · SetOrganization
  • Policies: RolePolicy · DeptPolicy · LoanPolicy · PFPolicy
Business Logic → Data

DATA LAYER

LAYER 04

Database & ORM

Persistence Foundation

  • Eloquent ORM (PHP ActiveRecord)
  • MySQL 8.0+ / PostgreSQL
  • 14+ core models with organization scoping
  • Migrations and Seeders for schema versioning
  • Soft deletes and global scopes (organization)

Relationship Types

  • hasMany: Employee → Attendances, Salaries, Payrolls, Leaves, Overtime, Bonuses, Loans, PF
  • belongsTo: Employee → Department, Designation, Organization
  • hasOne: Employee → CurrentSalary, LatestEmploymentPeriod
  • many-to-many: Organization ↔ Users (pivot role)

Key Database Tables

organizations · employees · departments · designations · attendances · salaries · payrolls · leaves · loans · provident_funds

Data → Infrastructure

INFRASTRUCTURE LAYER

LAYER 05

System Infrastructure

Runtime & Operations

  • Cache: daily operations caching
  • Session: DB-backed storage
  • Queue: database queue — payroll processing, report generation
  • Storage: avatars, payslips, documents
  • Artisan: custom commands (run payroll, seeder tools)
  • .env: DB connection, JWT keys, app settings

Optimization & Background Jobs

  • Config cache · Route cache · View cache
  • ProcessPayroll
  • GeneratePayslip
  • SendNotification
  • ExportReport

Caching Strategy

Daily cache refresh · frequently accessed employee data · organization settings.
